<h2 align = "left">About</h2>

- Number Race! A Termux game that made entirely on `Python`
   - if you want other **programming languages** as `C#`, `Node.js` or other else, please make suggestions, I will make 3 extra of these so `Python` won't be alone!
- If you want source code, type `nano file.py`
- The file will always be `.py` so it's could be understandable
   - (as `.cs` and etc..)
> [!NOTE]
> There a file `numberrace_save.json` it's cause some saves when you play, if you remove it, everything will be reset
<h2 align = "left">Tutorial</h2>

1. Download [Termux](https://github.com/termux/termux-app)
2. Type `pkg install python` (make sure it's latest! If not, use `pkg upgrade -y`)
3. Install a `.py` file from [releases](https://github.com) or [nightly]() 
4. Put it on Termux Folder (you can use `ls` to check if there's or not)
5. Type `python NumberRace.py` to execute
