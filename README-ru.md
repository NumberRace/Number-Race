- Игра сделано полностью в `Python`
- Это проект с открытым исходным кодом.

> [!NOTE]
> Если ты хочешь другие языки как `Lua`, `Ruby` или `C#` и тд.. Сделайте предложение об этой! Я соглашусь 3 языка, если легкий или сложный..

> [!WARNING]
> Если ты видел файл `numberrace_save.json`, эти твой сохранения когда ты играешь! Не пытайся удалить его.. Твой прогресс будет.. **УДАЛЕН**. Наверное ты можешь *поменять* там..?
<h2 align = "left">Установка</h2>

1. Скачай **Termux** от [ГитХаб](https://github.com/termux/termux-app/releases) или [Гугл Плэй](https://play.google.com/store/apps/details?id=com.termux)
2. Напиши `pkg install python`
   - Если у тебя есть это, напиши `pkg update && pkg upgrade -y`
3. Введи это команд (или скопируй)
```
the game is still fixing some stuff rn.. stay turned yet!
```
